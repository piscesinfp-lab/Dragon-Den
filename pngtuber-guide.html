PNG Tuber Art Technical Specs

Draw each expression state as a separate PNG file with a transparent background. Recommended size: 1000×1000px minimum, 2000×2000px ideal — Veadotube scales it down. Keep your line art on a separate layer from shading so you can reuse the base drawing across states. Export each state as PNG with transparency (not JPG).

The Silhouette Test

Fill your character with solid black and look at the shape. If you can immediately tell it's her from the silhouette alone — horns, hair shape, hoodie — the design works at small sizes. This matters because your PNGtuber overlay will be maybe 300px wide on a 1080p stream. The horns and distinctive hair are what viewers will recognize instantly.

Expression States

The Eight States

Veadotube triggers states based on mic input and hotkeys. Draw these eight and you'll have full emotional range for any streaming situation.

😌
Idle — Closed
Neutral, calm, mouth closed. Slight soft expression — not blank. This is the default when you're not speaking.
Trigger: silence / no mic
🗣️
Talking
Mouth open mid-speech. Engaged, present expression. Same as idle but with open mouth — can be the same art with swapped mouth layer.
Trigger: mic input detected
😄
Happy / Laughing
Big smile, eyes slightly squinted. The "that's hilarious" face. Essential for gaming wins and chat interactions.
Trigger: hotkey (F1 or similar)
😤
Annoyed / Focused
Slight frown, narrowed eyes. The "this game is testing me" face. Dragon energy — contained irritation, not rage.
Trigger: hotkey
😱
Screaming / Shocked
Wide eyes, mouth open wide. Jump scare face, hype moment face. This one gets clipped constantly — make it dramatic.
Trigger: loud mic or hotkey
😏
Smug / Scheming
Half-smile, one raised brow, slightly narrowed eyes. The "I know exactly what I'm doing" face. Very on-brand for a dragon character.
Trigger: hotkey
🥺
Sad / Tired
Drooped eyes, soft frown. For emotional game moments, late-night streams, or "chat why did you do that to me" energy.
Trigger: hotkey
🐉
Dragon Mode
Full dragon expression — glowing eyes, bared fangs, scales more prominent. The hype state. Use for wins, raids, big moments.
Trigger: hotkey (save it for moments)
Drawing Order

Draw Idle Closed first — get the design locked in. Then draw Talking as the same drawing with a swapped mouth. Then Happy and Screaming — these get used most. Then fill in the rest. You can launch with just Idle + Talking + Happy + Screaming and add states over time. Don't let perfectionism delay your launch.

Software

What to Use

Three real options. One clear winner for where you're starting.

Veadotube Mini
The PNGtuber standard
⭐ Recommended
  • Free — pay-what-you-want, works fully for free
  • Mic-reactive mouth movement built in — talks when you talk
  • Multiple states with hotkey triggers
  • Bouncing animation when speaking — gives life to a static image
  • Drag and drop PNG import — incredibly easy setup
  • Outputs as a window you capture in OBS
  • Used by the majority of active PNGtubers on Twitch
  • Download: veado.tube
VTube Studio
More for Live2D but has PNG support
Later option
  • Primarily designed for Live2D models
  • Does support PNG mode but it's less intuitive
  • Worth knowing for when you want to upgrade to Live2D eventually
  • Free with limitations — paid features for advanced use
  • More setup complexity than Veadotube for PNG
  • Skip this for now — come back when you go Live2D
OBS Image Switcher
Manual, no software needed
Backup option
  • Use OBS hotkeys to manually swap between expression PNG images
  • No extra software needed
  • No automatic mic-reactive movement
  • Works but feels more static — no bounce or life
  • Good if Veadotube has issues but not ideal long term
  • Setup: Scene Collection → Image sources with hotkeys
OBS Setup

Stream Layout

You already have the three-monitor setup designed. Here's exactly how the stream layout works with your existing gaming rig.

🖥️

Monitor Assignment for Streaming

  • Center AOC 1440p: Your game — always the primary capture source in OBS
  • Left VA2247: OBS Studio running — scene switcher, stream health, chat visible
  • Right VA2247: Veadotube Mini window + browser for chat interaction
  • This is the exact three-monitor streaming setup — you designed it perfectly already
🎬

OBS Scene Structure

  • Scene 1 — Gameplay: Game capture full screen + PNGtuber overlay bottom left or right
  • Scene 2 — Just Chatting: Dark forest background + PNGtuber centered, larger
  • Scene 3 — Starting Soon: Animated overlay, no PNGtuber yet
  • Scene 4 — BRB: Forest ambience, looping animation
  • Scene 5 — End Screen: Thank you screen with socials
🐉

PNGtuber Overlay Placement

  • Veadotube runs as a separate window — add it as a Window Capture source in OBS
  • Set Veadotube background to transparent or chroma key green
  • In OBS: right-click source → Filters → Chroma Key to remove background
  • Position: bottom-left corner during gameplay — standard PNGtuber placement
  • Size: ~280–320px wide on a 1080p canvas — visible but not distracting
  • Just Chatting scene: centered, larger — she's the focus
🎨

Stream Background — Just Chatting

  • Your actual bedroom with the RGB lighting IS your background — most authentic option
  • Dragon shelf wall visible over your shoulder on webcam (if ever used)
  • OR: a drawn/illustrated version of your Dragon Den as a static background image
  • OR: a dark forest illustration — Lofi Girl energy but darker and more dragon
  • Overlay elements should match the room palette: jade · ember · gold on black
Veadotube in OBS — Step by Step

1. Open Veadotube Mini, import your PNG states, set up mic sensitivity. 2. In OBS, add a new source: Window Capture → select the Veadotube window. 3. Right-click the source → Filters → Add → Chroma Key (if using green BG) or Luma Key (if using black). 4. Resize and position in your scene. 5. Lock the source so you don't accidentally move it mid-stream.

Overlay Design

  • Dark near-black base (#07090a) — everything readable, nothing distracting
  • Thin jade or ember border elements — not chunky gaming overlays
  • Minimal text — stream title, social handle, maybe a subtle dragon watermark
  • Get overlays from Etsy — search "dark fantasy twitch overlay" for premade sets (~$10–25) or make your own in Canva
  • Font: Cinzel or a similar serif fantasy font — matches your whole aesthetic
🔔

Alerts + Notifications

  • Follower alert: brief dragon animation or ember particle burst
  • Sub alert: more dramatic — ember glow, dragon roar sound
  • Raid alert: Dragon Mode state triggers on the PNGtuber simultaneously
  • Use Streamelements or Streamlabs for alert boxes — both free
  • Keep sounds short — under 3 seconds. Nothing kills stream flow like long alert sounds
📋

Channel Panels

  • About Me: Dark forest / dragon aesthetic, who you are, what you stream
  • Schedule: Even a loose one builds expectation
  • PC Specs: Gamers want to know
  • Commands: List your chat commands (!discord, !socials, etc)
  • Rules: Keep it short — be kind, no hate speech, have fun
  • Design panels in Canva — dark background, jade/ember accents, Cinzel font
🎮

What to Stream

  • Steam library — you already play it, start there
  • DnD sessions if your group is comfortable being streamed
  • Just Chatting — cozy aesthetic streams do well with the right personality
  • Avoid: starting with huge games (Minecraft, Fortnite) — impossible to be discovered. Start with smaller games or niche titles
  • Your personality + your aesthetic IS the content — the game is secondary

The Most Important Thing

Stream consistently even when the viewer count is zero. The VODs get indexed. The clips get shared. The algorithm notices consistency before it notices quality. Your first ten streams are practice — they are not your debut. The debut is whenever you decide it is. Start messy, start now, get better in public.
