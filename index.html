How To Use This

Your Folder Setup

All files should be in the same folder on your desktop. Keep them together and everything links correctly.

File Folder Structure

Save all HTML files into one folder called "Dragon Den" on your desktop. Open index.html as your home base — it links to everything. Progress saves to your browser's local storage per-file, so use the same browser consistently to keep your checkmarks.

This Weekend — Open These First

movein-timeline.html — your Day 1 order of operations, clickable checklist. budget-tracker.html — mark things as purchased as you buy them. lighting-diagram.html — reference when installing RGB strips. Everything else can wait until you're settled in.
